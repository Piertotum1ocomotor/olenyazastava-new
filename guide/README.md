# Оленья застава · путеводитель по курорту

[Открыть сайт](https://piertotum1ocomotor.github.io/olenyazastava-new/guide/)

Новая версия размещена в папке `guide/` существующего GitHub Pages. Исходная главная, каталог и страницы курорта сохраняют свои адреса.

Внутри статические HTML, CSS, JavaScript, локальные шрифты и фотографии. Сборка и установка пакетов не нужны. Для локального просмотра из корня репозитория выполните `python3 -m http.server 8000` и откройте `http://localhost:8000/guide/`.

- `index.html` — тексты, ссылки на каталог, контакты, карту и действующий модуль бронирования.
- `styles.css` — типографика, сетка, мобильная версия.
- `site.js` — меню и просмотр фотографий; основные ссылки работают без JavaScript.
- [PHOTO-SOURCES.md](PHOTO-SOURCES.md) — происхождение фотографий.

Точные цены проживания и доступность выдаёт модуль бронирования. Примеры из прежнего каталога отмечены как архивные. На странице нет формы сбора данных, собственной оплаты и подключённой аналитики.
